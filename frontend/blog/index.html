Пользовательское соглашение

1. Общие положения

Настоящее Пользовательское соглашение регулирует отношения между владельцем сервиса MiruFlow и пользователем.

2. Предмет соглашения

2.1. Администрация предоставляет Пользователю право использования визуального редактора MiruFlow.

3. Права и обязанности сторон

3.1. Администрация обязуется:

  • Обеспечить работоспособность сервиса
  • Обеспечить конфиденциальность данных

3.2. Пользователь обязуется:

  • Предоставлять достоверную информацию
  • Не нарушать работоспособность сервиса

4. Интеллектуальная собственность

4.1. Все права на сервис MiruFlow принадлежат Администрации.

4.2. Пользователь сохраняет права на созданный контент.

5. Ответственность сторон

5.1. Администрация не несёт ответственности за временные перебои.

5.2. Пользователь несёт ответственность за созданный контент.

6. Конфиденциальность

6.1. Администрация обрабатывает персональные данные для предоставления услуг.
